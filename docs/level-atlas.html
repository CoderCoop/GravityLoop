Gravity Loop — level reference

Every level in plan view with its laziest winning route drawn: the straightest path the brute-force solver can find that still reaches the goal. A level is only as hard as its easiest solution, so this is the line that matters — if it runs from pad to goal through open space, the level is easy however elaborate the rest of the map looks. Levels where a direct shot is still possible are outlined in red.
